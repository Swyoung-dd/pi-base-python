# piY 项目文档

这里沉淀 piY 的长期技术文档。根目录的 `README.md` 面向安装和日常使用，
本目录面向需要理解、维护或扩展项目的开发者。

## 文档导航

- [项目架构](architecture.md)：系统分层、运行链路、核心数据流和模块边界。
- [设计思想](design-principles.md)：关键设计选择、取舍以及后续演进约束。
- [开发指南](development.md)：环境、常用检查、代码变更路径和交付标准。
- [扩展指南](extensions.md)：如何增加 provider、模型、工具、Skill 和运行时扩展。

## 阅读建议

第一次接触项目时，建议依次阅读“项目架构”和“设计思想”；准备修改代码时，
再阅读“开发指南”和对应的扩展章节。

这些文档描述仓库当前实现，而不是独立于代码的目标蓝图。涉及公共类型、运行链路、
配置项或扩展协议的变更，应在同一个变更中同步更新相应文档。
